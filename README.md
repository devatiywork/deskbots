# DeskBots

Пиксельный офис прямо на рабочем столе Windows: в нём сидят твои открытые ИИ (Claude Code, Claude, Codex, ChatGPT, Ollama и др.), работают, пьют кофе, болтают, ходят на брифинг, а за окном — Владивосток.

Это самостоятельное приложение на [Tauri](https://tauri.app): ни Wallpaper Engine, ни Node.js не нужны. Офис встраивается под иконки рабочего стола на всех мониторах или на выбранных, на самих обоях — панель с кнопками, а все настройки — в отдельном окне (значок в трее).

## Установка

Скачай `DeskBots_<версия>_x64-setup.exe` со страницы [Releases](../../releases) и запусти. Права администратора не нужны: приложение ставится только для текущего пользователя. Установщик не подписан, поэтому Windows SmartScreen может спросить подтверждение («Подробнее → Выполнить в любом случае»).

Нужны Windows 10 или 11 и WebView2 (в Windows 11 уже есть). После первого запуска откроется окно настроек, офис появится на рабочем столе, а хуки Claude Code и Codex пропишутся сами; в Codex их нужно один раз одобрить командой `/hooks`.

## Что внутри

| Папка | Что это |
|---|---|
| `app/web/` | Интерфейс на React + TypeScript + SCSS по Feature-Sliced Design: обои с офисом (`wallpaper`) и окно настроек (`settings`). Все тексты — в `src/shared/i18n/ru/*.json`. Карта кода — `app/web/ARCHITECTURE.md`. |
| `app/src-tauri/` | Приложение: окно обоев под иконками, пересылка мыши, трей, автозапуск, настройки. |
| `app/core/` | Сервер офиса на Rust: процессы ИИ, события хуков, сводка дня из логов Claude Code, лимиты, нагрузка ПК, кубки. |
| `app/hook/` | `deskbots-hook.exe` — хук Claude Code и Codex. |

## Офис

- **Агенты** — открытые ИИ-программы. Claude Code и Codex сообщают через хуки, чем заняты: над головой видно файл или команду (у долгой команды — сколько она идёт), на мониторе — папка проекта. Клик по агенту выводит вперёд окно его программы.
- **Реакции:** упала команда или тесты — красный «!», тесты прошли или коммит — зелёная галочка, `git push` — гонг и конфетти. Субагенты приходят стажёрами в жёлтых кепках и встают у стола.
- **Ждёт тебя:** лампа на столе и вывеска мигают, через две минуты ожидания повторный звук.
- **Табло дня** на доске: файлы, команды, коммиты, токены за сегодня; по очереди с графиком токенов за неделю. Вечером брифинг подводит итоги дня, в пятницу — недели.
- **Билборд** во дворе: загрузка процессора, видеокарты и памяти, окно 5 часов Claude со временем сброса, лимиты Codex за 5 часов и неделю.
- **Серверная стойка** мигает от нагрузки ПК и дымится при перегреве. **Шкаф с кубками** — 10 достижений (100M и миллиард токенов за день, 7 дней подряд, ночная смена, push в пятницу вечером и др.).
- **Распорядок:** отошёл от ПК — свободные агенты уезжают домой; обед с пиццей; после конца рабочего дня и в выходные расходятся; поздно вечером напоминают лечь спать.
- **Время и место:** системное время, восход и закат по координатам (по умолчанию Владивосток), реальная погода с Open-Meteo, тайфун при сильном ветре, луна в настоящей фазе.
- **Владивосток за окном:** сопки, бухта, Золотой мост, порт; зимой лёд, рыбаки и ледокол, в тумане ревун. День тигра, День города с салютом, Новый год с гирляндой и ёлкой, производственный календарь РФ.
- **Вывеска** над офисом — своя надпись в две строки (русские и латинские буквы); сменишь её — неон включится с миганием, вылетят конфетти, агенты обсудят новое название.
- **Сценки:** чайка, доставка пиццы, пожарная инспекция, отключение света, кот Мурчик (клик по коту — вкусняшка), робот-пылесос (натыкается на агентов, а Мурчик, уснувший на нём, катается по офису), звонок клиента («сделайте как у Apple»), сломанная кофемашина (паника, Codex чинит: `sudo make coffee`), день рождения агента с тортом, свечами, песенкой и конфетти.
- **Разговоры:** агенты подкалывают друг друга (Claude, GPT, Codex, Ollama, Gemini, Grok, DeepSeek, Qwen, Mistral, Perplexity, Copilot), обсуждают работу по настоящим данным хуков, болтают за кофе и пиццей, изредка устраивают круг шуток.
- **Режим Grand Ermii** (выключается в настройках): руководство — Андрей и Сергей, разработчики, и Фёдор, владелец и начальник, — 1–4 раза за рабочий день приезжает на лимузине Grand Ermii, минут десять ходит по офису и уезжает. Пока оно в офисе, агенты бросают кофе и диван и сидят за столами; руководство заглядывает им через плечо, читает табло, пьёт кофе, проверяет холодильник («Чья это шаурма?»), разработчики играют в аркаду, двое из руководства сходятся поговорить (про код, релиз, бюджет), Фёдору звонят по телефону, и раз за визит он собирает всех и объявляет новость. Замечает push, упавшие тесты, новые кубки и смену вывески. Можно позвать сразу кнопкой в настройках.
- **Звуки** синтезируются на лету, без файлов: клавиатуры, кофемашина мелет и наливает, кулер булькает, гудки в трубке при заказе пиццы, трель телефона, колокольчик над дверью, шаги начальника, хлопки дверей машин, аркада, храп на диване, вибрация телефона, кукушка в часах каждый час, щелчки неона, гром, дождь, ветер, чайки, сверчки.
- **Режимы:** игра или видео на весь экран — 10 кадров в секунду и без звука; занят микрофон (созвон) — тишина.

## Приложение

- **Под иконками.** На каждом выбранном мониторе своё окно офиса становится частью рабочего стола; звук играет только окно на главном мониторе. В Windows 11 24H2 и новее иконки и фон — дочерние окна `Progman`, офис встаёт между ними слоистым окном; на старых версиях — внутрь отдельного `WorkerW`. Если Explorer перезапустится, опустит офис под фон или поменяется конфигурация мониторов, приложение встроит окна заново. Если монитор пропал (уснул, переподключается, меняет режим), его окно прячется и возвращается вместе с ним, офис при этом не начинается заново; окно закрывается, только если монитор не вернулся за полчаса. Что происходило с мониторами и окнами, видно в `server.log`.
- **Мышь.** Обои закрыты иконками, поэтому приложение смотрит движения и клики низкоуровневым хуком и пересылает их в офис того монитора, над пустым рабочим столом которого курсор. Рабочий стол при этом получает клик как обычно.
- **Настройки** (значок в трее → «Настройки»): мониторы, масштаб («чёткие пиксели» для 2K и 4K), защита OLED, пауза, автозапуск, сезон, погода, звук, координаты, вывеска, панель, режим Grand Ermii (руководство, имена, как часто), какие ИИ показывать, распорядок, тихие режимы, статистика, кубки, состояние сервера и хуков. Кнопки на обоях и окно настроек меняют одни и те же настройки.
- **Автозапуск** — строка в `HKCU\...\Run`, права администратора не нужны.
- **Данные** — `%LOCALAPPDATA%\DeskBots-Data`: `app-settings.json`, `token.txt`, `office-state.json` (история и кубки), `server.log`, `deskbots-hook.exe`.

## Сервер и хуки

- Сервер работает внутри приложения. Обои получают состояние напрямую, без HTTP. Наружу открыт только `127.0.0.1:7777` для событий хуков: каждый запрос должен нести ключ из `token.txt`, чужое имя хоста получает 421 (защита от DNS rebinding). Сайты в браузере не могут ни прочитать, какие ИИ открыты, ни подсунуть события.
- Нет автообновления. В интернет ходит только сама страница офиса — за погодой на Open-Meteo (уходят только координаты; выключается выбором другой погоды).
- Процессы, окно на весь экран, занятый микрофон и простой мыши — через Windows API, видеокарта — `nvidia-smi`, только пока офис на экране.
- Сводка дня читает только сегодняшние логи `~/.claude/projects/**/*.jsonl` и только дописанное с прошлого раза. Лимиты Codex — из `~/.codex/sessions`.
- `deskbots-hook.exe` при первом запуске прописывается в `~/.claude/settings.json` и, если Codex установлен, в `~/.codex/hooks.json` (с копией файла до изменения). Хук ничего не печатает, поэтому не попадает в контекст модели и не тратит лимиты; передаёт только событие, имя инструмента, короткую подпись (имя файла, первые слова команды) и вид команды (тесты, push, коммит, сборка) с кодом выхода. В Codex хуки нужно один раз одобрить командой `/hooks`.

## Сборка

Нужны Rust (stable, MSVC) и Node.js — для сборки интерфейса и сборщика Tauri; самому приложению Node не нужен.

```
cd app/web
npm install
cd ..
npx @tauri-apps/cli@2 build
```

Сборщик сам собирает интерфейс (`npm run build` в `app/web`). Установщик для текущего пользователя (без прав администратора) появится в `app/target/release/bundle/nsis/`.

Сцены офиса можно проверять в обычном браузере: `cd app/web && npm run dev`, затем открыть `http://localhost:5173/wallpaper/index.html#demo-fast-push-interns`. ## Удаление

«Параметры → Приложения → DeskBots → Удалить». Хуки в настройках Claude Code и Codex удаляются отдельно: в окне настроек на вкладке «Сервер и хуки».
